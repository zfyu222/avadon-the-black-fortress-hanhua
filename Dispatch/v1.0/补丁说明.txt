《阿瓦登：黑色要塞》子非鱼AI汉化补丁 v1.0
========================

为《Avadon: The Black Fortress》Steam Windows 版制作的简体中文 AI 汉化补丁。离线运行，无需 API 密钥。

发布日期：2026-10-26

适用版本
Steam Build 4252712 / Avadon v1.0s2
Steam Windows 11 x64（游戏与补丁均为 x86）

汉化内容
已提取并完成翻译/独立审校的正文 15,928 条，以及已确认的图片文字 98 条。载荷包括中文显示适配 DLL、离线词典和 19 张修改贴图。图片为确认子集，不能据此承诺全游戏无漏字。

安装方法
完全退出游戏。先备份游戏根目录 Avadon.exe（用于版本核对，补丁不会覆盖它）及 Avadon Files/Graphics Core 下这 11 个原文件：G128.png, G133.png, G153.png, G158.png, G159.png, G165.png, G167.png, G169.bmp, G189.png, G203.png, G220.png。
若游戏根目录已有其他来源的 winmm.dll，请先停止安装并处理 MOD 冲突，不要直接覆盖。
将 ZIP 中 winmm.dll、AvadonChinese 文件夹和 Avadon Files 文件夹复制/合并到 Avadon.exe 所在目录，同意覆盖上述已备份的图片文件。不要额外套一层文件夹。随后从 Steam 正常启动。
游戏 EXE、脚本和 DAT 不修改；新增的 winmm.dll 会在运行时挂钩文字绘制/测宽。字体使用系统 Microsoft YaHei（微软雅黑），不附字体或系统 DLL。

卸载 / 恢复
完全退出游戏。删除游戏根目录本补丁新增的 winmm.dll 和 AvadonChinese 文件夹（反馈前可保留其中日志）；删除 Avadon Files/Graphics Core 下新增的 G129.png, G142.png, G143.png, G176.png, G177.png, G231.png, G232.png, G233.png；用安装前备份恢复上述 11 个原图片文件。
仅验证 Steam 文件完整性不会自动删除这些新增文件，卸载时仍需删除它们。不要删除原有同名 JPG。补丁说明和校验文件可一并删除。

实机验证
用户确认已检查修正 retrain 后的最新版，并答复“检测过了”，随后要求发布。按用户确认记录字体、排版、菜单、对白和任务推进检查；未另提供本轮具体任务名称或新版逐项截图，不宣称全流程通关。
离线组件、字体字形覆盖、完整词典、贴图尺寸/边界、安装哈希检查通过；代理未启动游戏。发行 ZIP 另做干净目录安装/卸载及逐文件校验。
