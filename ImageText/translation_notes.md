# 图片原文交接说明

本轮正式原文为已视觉确认的子集：98 条去重文本、133 个位置。10 张图片仍有局部未决，不能把当前 CSV 当作全图转写完成。

- `preserve_rows.json` 绑定源文哈希，列出字形序列、资源标记、数字与图示字母等建议保留项。它是交接提示，不表示翻译流程已经配置了禁翻规则。进入 `game-translate` 时应正式纳入术语/保护规则。
- `ABCDEFGHIJKLMNOPQRSTUVWXYZ` 来自 G290 位图字体图集，不翻译成中文句子；图集另按字体资源适配。
- `G133` 是贴图内的资源标记，保持原样。数字、问号、感叹号、罗盘 N、教程 A-E 标记应保留；教程说明译文需与字母箭头保持对应。
- 两个尺寸的标题分别保存位置。Spiderweb / SOFTWARE / TM 属于开发商标志，应谨慎保持品牌形式。
- 世界地图地名与常规文本共用术语。地图使用小型大写字形；原文按可见字形转写，不能把图片位置误当脚本可替换位置。
- 不根据同名脚本、模型建议或其他图片填补截断字母。跨贴图的地名应在合入阶段检查拼接布局。
- 教程截图本身含极小 UI 文字；目前只导出清楚可读的区域。血迹遮挡的地图成就、部分字形图集和药瓶标签仍列为未决。

所有正式区域由当前对话 Agent 实际看图后通过 `agent-import` 导入，`human_approval=false`。模型 no_text 与筛选排除均未当成人工确认。
